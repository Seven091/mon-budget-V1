# Mon Budget

Application personnelle de pilotage budgétaire.

## Objectif

Transformer un système de gestion budgétaire Excel en application web simple, mobile et prédictive.

## Fonctionnalités V1

- Tableau de bord mensuel
- Revenus
- Dépenses
- Charges fixes
- Enveloppes budgétaires
- Prévu / réel
- Reste disponible
- Alertes
- Objectifs d'épargne
- Historique des transactions
- Analyse mensuelle
- Stockage local

## Technologies

- React
- Vite
- JavaScript
- Lucide React
- LocalStorage
